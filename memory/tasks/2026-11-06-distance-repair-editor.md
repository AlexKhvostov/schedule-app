Ошибка записи сохраняет ввод, двойное сохранение блокируется. Escape/Tab и возврат фокуса проверены. Для нового part учитываются месяц, рум, вид и конкретный ID; при смене периода сначала читаются записи выбранного периода. Основной и дополнительный ID различаются в списке.
