## Итог

- «Актуально» требует подтверждённого канала и полной сверки. Наличие ранее загруженного снимка само по себе не разрешает новую запись.
- После обрыва/фона — новые правки закрыты, старые данные видимы; незавершённый жест отменяется, прежнее подтверждение вытеснения закрывается. При попытке правки открывается карточка с восстановлением. Старые клики не воспроизводятся.
- Полное чтение включает строгие настройки, мёртвое время и обе ёмкости. Ошибки правил не подменяются значениями по умолчанию. Принятие снимка и контекста защищено от позднего ответа/смены месяца/локальной записи.
- Deadline чтения15с, автоматический повтор (включая первую ошибку), дополнительная сверка видимой вкладки через30с, предельный возраст60с. Потерянный канал пересоздаётся при ручном повторе/резервной попытке; завершение старой подписки ограничено5с.
- Неподтверждённая запись после20с остаётся в ожидании исходного результата и блокирует следующие. Не отправляется повторно. Явная перезагрузка сопровождается инструкцией проверить результат метки.
- На телефоне до600px статус — значок с доступным названием; подробности раскрываются по нажатию. Деморежим показывает «Демо».
- «Онлайн» переименован в «На сайте»/On site. Список и сортировка неизменны. Следующая отдельная задача: проверить жалобу, что недавние посетители расположены ниже давних.
- Начальный пакет после новых переводов превышал бюджет на0,7KiB. Экран входа и заявки вынесены в React lazy/Suspense; итог255,5/260KiB. Вариант отложенной загрузки OnlineMenu не помог и отменён, его логика не менялась.

## Границы и передача

Это локальная реализация, не релиз. Git push/публикация не выполнялись. В реальном авторизованном Working/Production интерфейс этого изменения ещё не проверен; текущий просмотр IAB — Demo, сценарии сети проверены на синтетическом сервере. Реальный физический сон телефона не имитировался: проверены browser visibility и контролируемые ответы сети.

Ёмкость обновляется при полной сверке/возврате и контрольном опросе, не мгновенным отдельным событием: capacity-таблицы не опубликованы в текущем Realtime. Статус не обещает абсолютной одновременности между пользователями. Сервер продолжает проверять каждую запись. При увеличении нагрузки следует оценить стоимость периодических полных чтений и перейти на лёгкую серверную ревизию.

Параллельные изменения Dashboard и его документация сохранены. E2E обновляют прежние снимки в memory/tasks; до запуска часть снимков уже была изменена другим чатом, ничего не откатывалось. Отдельного коммита не создавалось, чтобы не включить общие незавершённые изменения. Следующий шаг: пользователь смотрит локальный вариант/снимки; публикация только по отдельному поручению.
