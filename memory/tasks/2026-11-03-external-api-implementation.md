## Проверенное окружение

Docker29.9.2 успешно запущен; создан отдельный локальный проект `redparty-api-check-20261103` в игнорируемом `supabase/.temp/external-api-check`, API55481/БД55482. Миграции и seed пересобраны с нуля; облачные подключения не использовались. Deno2.9.6 запущен из npm-cache без глобальной установки; runtime-код API не имеет сторонних импортов. Supabase CLI2.119.0.

Database lint: ошибок нет; прежние предупреждения в `hours_of` (переменная i) и `save_distance_dump` (неиспользуемый параметр) остаются, новые функции без замечаний.

Настоящий HTTP-тест: 1106 меток возвращены целиком; фильтры/пустые даты/ошибки проверены; 10 одновременных запросов с тестовой квотой2 дали ровно2 успеха и8 ответов429. Временные ключи сгенерированы только для одноразовой локальной базы и сохранены только в git-ignored `.temp`.

Повторная подготовка проверена штатным `tools/prepare-local-tests.ps1`: случайные ключи сохраняются в git-ignored `.env.integration`, затем все4 HTTP-теста проходят повторно. Ключи облака не выпускались. Локальная инструкция и PowerShell-утилита запрещают нелокальные адреса тестов.

Первый E2E через npm не передал workers=2, стартовал8 процессов и завершился OOM Node. Прямой `node node_modules/@playwright/test/cli.js test --workers=2` с портом3107 прошёл полностью:38 passed/1 skipped. Изменение tsconfig, автоматически добавленное проверочной сборкой (`.next-api-check`), убрано точечно, прежние пользовательские include сохранены.
