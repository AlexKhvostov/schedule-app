## Реализация

- `apps/web/src/schedule/lockedSlotAppearance.ts`: общая строгая модель, контраст чёрного/белого текста, группировка смежных получасов.
- `apps/web/src/data/lockedSlotAppearance.ts`: отдельное чтение/RPC; используется существующая подписка/минутная сверка ClubLimitPaletteProvider. Отказ этой загрузки не стирает палитру/оттенок, редактор отключён до восстановления.
- `LockedSlotEditor` находится внизу ёмкости, свёрнут вместе с ней по умолчанию; черновик переживает сворачивание. Общие подписи, два цвета, отдельное сохранение и предпросмотр обеих тем.
- Короткая подпись на плашке, длинная — в существующей подробной подсказке по нажатию. При нехватке места CSS-многоточие. Подписи необязательны. По умолчанию merge=true, цвета #d5dbe4/#343e50, текст пустой.
- Плашка не перехватывает указатель и не участвует в поиске игроков. Реальные метки поверх сниженной ёмкости сохраняются. Нет новых анимаций/таймеров/ResizeObserver на клетках.
- Миграция `20261105093758_locked_slot_appearance.sql`: колонка settings, валидатор, защищённая атомарная RPC. В Working применена в разрешённом выпуске 5 ноября.
