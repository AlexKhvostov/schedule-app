## Реализация

`V2UserCard` показывает кнопку всем. `V2Shell` передаёт существующее право управления пользователями/root; обычного управления расписанием недостаточно. Для недоступного действия есть «Доступно только администраторам». Закрытие формы сохраняет месяц, фильтры, список и обычную карточку.

`ScheduleMemberProfile` загружается лениво по разрешённому нажатию, получает административный снимок через прежний слой данных, выбирает точный memberId. Загрузка/ошибка/повтор/отмена не открывают чужую или пустую форму. Поздний ответ после размонтирования игнорируется. Обновление имени перечитывает публичное имя в исходной карточке.

`AdminPersonEditor` объединяет существующий AdminPersonCard, действия доступа и сохранение метки. MarkModal вынесен из MembersAdmin без второй реализации. Существующий список пользователей использует тот же компонент. Схема, RPC, RLS и разрешения рабочих аккаунтов не менялись; миграция не нужна. Новых зависимостей нет.
