## Уточнение размещения и API — 2026-11-05 16:57 Europe/Minsk

Пользователь подтвердил сохранение работающего PHP и рассматривает повторное использование текущих endpoints либо небольшую оптимизированную обвязку. Упомянуто ограничение «на HostLand только статические файлы»; запрошено уточнение, означает ли оно отсутствие постоянного Node.js или PHP работает отдельно. Конфигурация конкретного тарифа/сайта не проверена. Исходный deploy-README описывает PHP API вместе со статикой на Hostland; официальная документация Hostland подтверждает общую поддержку PHP, но не настройки аккаунта.

Предложение для обсуждения: начать с существующих PHP-операций и форматов, добавить серверную проверку входа/прав и замерить реальные узкие места. Серверный шлюз не обязан быть Node/Next.js: проверка может выполняться непосредственно в PHP с вызовом React → PHP по HTTPS. Тогда потребуется настройка CORS под источник приложения и проверка токена/активного участника на каждом запросе; прямые незащищённые пути недопустимы. Исторически на момент этого уточнения путь ещё не был выбран; последующим подтверждением выбран прямой HTTPS-доступ React к защищённому PHP API (см. ниже). SQL/агрегаты оптимизировать по измерениям, не переносить тяжёлые расчёты/сырые базы в браузер.
