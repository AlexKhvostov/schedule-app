# Шапка «Игроков месяца» при прокрутке

Обновлено: 4 ноября 2026, 19:29 Europe/Minsk. Источник: поручение Алексея. Статус: готово локально, без публикации.

Цель: строки и метки полностью уходят под непрозрачную шапку, закреплённую у верхней границы прокрутки. Только список игроков месяца.

| Этап | Статус | Критерий |
|---|---|---|
| Причина и CSS | Готово | Локальная изоляция слоёв меток, без просвета сверху |
| Проверки | Готово | Длинный список, обе темы, один/два вида, узкий экран; сборка и тесты |
| Документация и итог | Готово | Фактический результат и снимки, локальный коммит без push |

Причина: у шапки z-index 1, общие метки имеют тот же z-index1 и рисуются позже шапки; padding-top прокручиваемой области оставлял просвет. Решение: локальный класс окна с нулевым верхним padding, изоляция tbody на уровне0 под шапкой. Отступ закладок сохранён. Общие стили меток и других окон не меняются.

Проверено: IAB, прокрутка укороченного окна; автоматизированный сценарий40 дополнительных игроков, обе темы, ширины1280/390, три позиции прокрутки, один/два вида. Проверка точек шапки подтверждает, что метки действительно ниже неё, а шапка совпадает с верхом scroll-области. Снимки осмотрены: [тёмная тема](2026-11-04-roster-scroll-dark.png), [светлая тема](2026-11-04-roster-scroll-light.png). Полный прогон: 75 E2E успешно, 2 штатно пропущены (внешняя авторизация и отдельная интеграция профиля с авторизационным состоянием). 204 unit, typecheck, lint, build и bundle 257,7/260 KiB — успешно.

Технические повторные запуски: начальное ожидание общего количества строк в новом тесте уточнено до40 синтетических игроков.
