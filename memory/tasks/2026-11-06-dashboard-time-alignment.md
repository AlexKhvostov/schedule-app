Рабочее решение: час карты — интервал от h:00 до h+1:00. Нижняя шкала подписывает те же часовые интервалы по центру, линия остаётся точной по минутам внутри интервала. Изменение видимого времени применяется к обоим блокам, без перерасчёта суточных показателей. Реальная ширина столбцов карты определяет координаты графика; горизонтальная прокрутка синхронизируется. Подсказка использует верхний слой браузера через native popover, сохраняя тему. Шапка Свои и чужие остаётся; внутри кнопки слова убираются, доступные пояснения сохраняются.

Реализованы PointsCharts с общей геометрией/диапазоном/scroll, левая легенда линий, hourly bands SVG и native popover подсказки. Поле диапазона переименовано в «Часы с/до», чтобы явно относилось к обоим блокам. СуточныеΣ и фильтры не изменены. Новые E2E измеряют центры24часов, zoom, Top/вертикальный scrollbar, синхронизацию двух scroll и фактическое перекрытие tooltip.

Промежуточно:4новых браузерных сценария геометрии/top-layer PASS в обеих темах;348unit/70files PASS (exit0, прежние Windows EPERM при закрытии workers),typecheck/lint/build/bundle255.9/260KiB PASS. В прежнем UI-тесте точка hover100px теперь попадает на левую легенду: тест исправлен на250px внутри области графика. Итог общего E2E приведён ниже. Синтетические desktop/zoom снимки и видимая поверх шапки таблицы подсказка осмотрены.

Живая браузерная проверка:10игроков,24часа, максимальная разница центров0.3985px,0pageerrors,без мутаций/сохранения ников. Общий прогон выявил закрытие tooltip при автоматической прокрутке к фокусированному значку на телефоне: обработчик теперь обновляет позицию при фокусе и закрывает за пределами видимой области. Повторные проверки успешно завершены после окончания горячего обновления: промежуточный прогон во время HMR потерял CSS аналитики (видно по скриншоту), что не использовано как подтверждение геометрии.


## Итог и проверки

- PointsCharts связывает24часовых интервала, видимый диапазон и горизонтальную прокрутку. Слева — включение/выключение ников линий; суточныеΣ и расчёты не изменены.
- Tooltip отображается в top layer, корректно следует за фокусом при автоматической прокрутке на телефоне. Кнопка «Реги» содержит только название/два символа/числа под сохранённым заголовком.
