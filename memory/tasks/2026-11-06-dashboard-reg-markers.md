# Метки регов и быстрое добавление с карты

Обновлено: 2026-11-06 02:46 Europe/Minsk. Готово локально.

Поручение Алексея: явно подписать цветные счётчики своих/чужих на общей кнопке; отметить участников registry рядом с никами карты; заменить предзаполнение массовой формы «В реги(N)» отдельным окном списка текущей карты с индивидуальными кнопками в свои/чужие. Общая кнопка и полные списки остаются отдельными.

| Этап | Статус | Критерий |
|---|---|---|
| Контекст/источники | Готово | main=origin/main, предыдущий registry и read-back используются |
| Счётчики/метки | Готово | Красный бриллиант Red Party / синий контурный кристалл чужих; пояснение; вне registry нет метки |
| Быстрое окно | Готово | Только ники текущей карты, индивидуальные действия, текущая сторона, ошибки/защита повторов |
| Проверка | Готово | Изменение стороны/метки, выбранный Top, клавиатура/телефон, web checks |
| Документы | Готово | Новая модель замещает старое предзаполнение; отчёт и снимки |

Пользователь разрешил отличающийся способ маркировки. Окончательное решение после уточнения: компактные SVG-символы; цвет совпадает со счётчиком. Список быстрого окна фиксируется при открытии, чтобы строки не исчезали при изменении группы и фоновом обновлении отчёта. Подтверждённая сторона/метки обновляются сразу после read-back. Реальные тестовые записи не выполняются. Productionguard и PHP не меняются.

Уточнение Алексея: компактная таблица Ник / Список / Действия. У записанных игроков только приглушённое удаление; у незаписанных две цветные кнопки добавления. Удаление подтверждается внутри строки, затем возвращаются две кнопки. Окно520px, компактные строки; общие списки остаются широкими.

Уточнения Алексея: вместо букв RP/R — красный бриллиант Red Party и символ чужих того же семейства; рабочий выбор для чужих — синий контурный кристалл другого силуэта. Иконки SVG, общие для карты, списков и счётчиков. Основная кнопка переносится целиком в левую навигацию, верхняя удаляется. На телефоне кнопка остаётся в адаптивной панели навигации. Прямой старый маршрут /regs сохраняется, но дублирующий пункт меню убран.

Промежуточная проверка до последних уточнений:342unit,124E2E+2skip,7тематических,types/lint/build/bundle255.9KiB PASS; снимки dark/light desktop/phone осмотрены. Повторная тематическая и полная проверка новых символов/навигации завершены успешно (см. итог).
