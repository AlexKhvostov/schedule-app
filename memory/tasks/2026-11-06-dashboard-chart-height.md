# Points: размер графика, ползунок и карточки; Speed: управление регами

Обновлено: 2026-11-06 03:22 Europe/Minsk. Этап: готово локально.

Цель по поручениям Алексея: менять высоту нижнего графика, совместить ползунок с часовой шкалой, компактно показать карточки без внутренней прокрутки и с символами регов; добавить символы, список и действия управления регами в таблицу «Скорость».

| Этап | Статус | Критерий / результат |
|---|---|---|
| Высота графика | Готово | Мышь, touch, клавиатура; 180–800px, старт/сброс 210px; шрифт и шкала X не растягиваются |
| Ползунок времени | Готово | Центр бегунка совпадает с вертикальным курсором: <1.5px, включая zoom и прокрутку |

| Speed: регистры | Готово | Ярлык и столбец списка; две кнопки добавления либо удаление с подтверждением; счётчики и отфильтрованный отчёт обновляются |

Высота сохраняется при смене Top/фильтров в открытой PointsPage; после ухода со страницы сбрасывается. При большом Top карточки занимают дополнительные строки, страница может стать выше. Это рабочие решения реализации, без нового долговременного хранения.

RegRowActions — общий компонент для QuickRegsPanel и SpeedRanking. Используются существующие useRegistry.mutate и серверная проверка повторным чтением. Во время записи действия блокируются; при неподтверждённом сохранении показывается ошибка и обновление списка. Реальные записи при проверках не выполнялись: только Demo и перехваченные HTTP-ответы.
