## Реализация и проверки

- Временные ошибки Auth/профиля/контекста прав пробрасываются в единый контроллер восстановления: один запрос одновременно, deadline15с, повторы5/10/20/30с; поздние ответы после выхода/отмены игнорируются.
- Открытая сессия и таблица сохраняются, но запись заблокирована; после восстановления нужна полная сверка. Подтверждённый SIGNED_OUT/отозванная сессия и успешно проверенная блокировка по-прежнему закрывают доступ.
- Ошибка самого первого входа показывает retry, не форму входа и не приватные данные из localStorage. Сохранение снимка относится к уже открытой странице, не к перезагрузке браузера.
- Карточка актуальности только по индикатору, без intro и открытия при попытке правки; предупреждение поясняет доступность старых данных.
- Typecheck, lint, финальная production build PASS; bundle257,7/260KiB PASS. Unit374 PASS (73файла).

Готово для просмотра/следующего согласованного выпуска. В этой задаче нет commit/push/деплоя, миграции не нужны. Предыдущие локальные изменения присутствия и два коммита аналитики сохранены.
