# Минимальная ширина «Игроков месяца»

Обновлено: 28.11.2026 19:10 Europe/Minsk. Источник: Алексей сообщил о горизонтальной прокрутке при сужении окна в production после замены правой галочки переключателем; локально дефект не замечался.

Цель выполнена: причина подтверждена в опубликованном интерфейсе, локальное исправление проверено. Публикация не выполнялась.

| Подзадача | Статус | Критерий и результат |
|---|---|---|
| Код и расчёт ширины | Готово | Учтены столбец готовности, фиксированные столбцы, шапка и scrollbar |
| Production/IAB | Готово | 35 игроков; при минимуме 208 px тело имело clientWidth 191 / scrollWidth 198, превышение 7 px. Вертикальная полоса занимала 16 px |
| Локальное сравнение | Готово | Причина — в минимуме отсутствовала ширина вертикальной полосы; короткий список без неё скрывал ошибку |
| Исправление | Готово | ScheduleRoster измеряет полосу через ResizeObserver; V2Schedule добавляет её к минимуму и начальному размеру. Overlay-полоса даёт 0; учтён также минимум шапки при пустых колонках |
| Проверки и документация | Готово | Проверки ниже; состояние, UX, архитектура и журнал работ обновлены |

## Проверки

- Typecheck, lint, 516 unit-тестов, production build — PASS; bundle 242.4 / 260 KiB.
- Новая E2E-регрессия — 2/2 PASS в общем прогоне: 40 игроков, обе темы, занимающая место полоса 16 px и overlay-полоса 0 px, три очереди, мёртвые часы включены/выключены. Проверяется фактическая геометрия таблицы и отсутствие горизонтального превышения.
- Полный Demo E2E: 186 PASS, 2 SKIP, 1 FAIL (известный нестабильный Dashboard help: speedHours/speedRanking). Отдельный повтор справки — 4/4 PASS. Код Dashboard в этой задаче не менялся.
- Изолированный сервер проверки: порт 3112, `.next-e2e-roster-width`, 2 workers. Сохранённые до прогона изображения восстановлены без отката чужих изменений.
- Снимки проверены визуально: [светлая тема, обычная полоса](roster-min-width/minimum-classic-light.png), [тёмная тема, overlay](roster-min-width/minimum-overlay-dark.png).
- Изменённые локальные Markdown-ссылки и diff проверены. База, API, зависимости и пользовательские тексты в этой правке не менялись.

## Безопасность и следующий шаг

В production переключатели «Готово» и данные не менялись; исходный размер окна 334×532 восстановлен, временная вкладка закрыта. Основная пользовательская вкладка локального сервера сохранена: http://127.0.0.1:3000/#schedule.

Исправление находится в основной рабочей папке main вместе с ранее существовавшими изменениями. Push и публикация требуют отдельного поручения. Обновление страницы нынешней production-версии само по себе дефект не исправит. После согласованной публикации повторить сужение длинного списка в production.

Навыки: ui-ux-pro-max — проверка компактности и поведения; session-memory — фиксация результата и проверок.
