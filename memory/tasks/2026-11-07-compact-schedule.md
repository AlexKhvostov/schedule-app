## Дизайн и результат

Применён [frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md), прочитан без установки программ. Использован [принцип близости](https://www.nngroup.com/articles/gestalt-proximity/): связанные элементы располагаются ближе. Существующие палитра, шрифты, компоновка, цвета лимитов и меток сохранены.

- Внутри лимита: 2 px между краями слотов, без дополнительной линии.
- Между лимитами: 6 px, тонкий пунктир (18% foreground).
- Между видами турнира: 10 px, сплошная линия (30%).
- Между днями: 14 px, наиболее заметная общая рамка (44% в смеси с поверхностью дня).

Эти числа — измеренные расстояния между слотами с учётом всех внутренних отступов и границ, а не только CSS gap. При мобильном масштабе порядок сохраняется. Подписи слева выровнены по дорожкам. В уменьшенном обзоре телефона одна подпись на группу лимита предотвращает наложение текста; при масштабе редактирования возвращаются все подписи и номера уровней.

На одинаковых Demo-данных с пятью строками Nitro (50=3, 100=2) шаг дня с промежутком составляет **126 вместо 170 px**, уменьшение на **25,9%**. Метки **20×20 px**, ширина сетки **1181 px** при viewport 1280 сохранены. Исходные отступы воспроизведены CSS в той же тестовой странице, чтобы сравнить одинаковые данные и размер окна; это не отдельный запуск main.

В пользовательском IAB на http://127.0.0.1:3107/#schedule настроено **Nitro 50=3, 100=2** для всех часов недели; месячное переопределение выключено. Для сравнения видов включён также Regular (по 1 строке). Рабочая база не вызывается. Настройки относятся к Demo в этом браузере, не к серверу.

## Проверки

- `npm run typecheck`, `npm run lint`: успешно.
- `npm test`: **397 тестов в 78 файлах**, exit 0. Vitest вывел предупреждение завершения worker-процессов; тестовых ошибок нет.
- Полный `npm run test:e2e` с одним worker: **159 passed, 2 skipped, 1 failed** за 11,1 минуты. Единственный сбой — справка dashboard ru/dark открыла speedRanking вместо speedHours; причина нестабильности не установлена. Все сценарии расписания прошли.
- Отдельный повтор после последней CSS-правки: **10/10 passed** — шесть новых тестов компактности и четыре теста справки, включая упавший. Итого 160 разных E2E имеют успешный результат; это не один полностью зелёный общий запуск. Два штатных пропуска относятся к live Discord и реальному локальному admin-профилю.
- Отдельно **8/8**: компактность и `day-boundaries` до последней правки мобильных подписей. Проверены линии, закреплённый край, обе темы, мобильные обзор/редактирование/максимальный масштаб.
- IAB: визуальный просмотр и DOM-замеры реального Demo с обоими видами. При дробном масштабе экрана зазоры 2 / 5,67 / 9,67 / 13,33 px сохраняют порядок.
- Финальные мобильные снимки просмотрены: повторные подписи не накладываются. Снимки компьютера просмотрены в обеих темах.
- Финальный production build после мобильной правки: успешно, включая types/lint; `npm run bundle:check`: **231,7 / 260 KiB gzip**, в пределах бюджета.

## Границы и следующий шаг

Изменения приложения: `OptField.tsx`, `v2.css`; проверки: новый `compact-schedule.spec.ts`, обновлённый `day-boundaries.spec.ts`. Документация: current-state, decisions, schedule-ux, local-workspace, operations, work-log; память и снимки этого эксперимента.

Main, сервер и БД не изменялись, push не выполнялся. Чужие незавершённые файлы не включать в коммит. После просмотра Алексей может принять вариант или продолжить настройку. Для возврата есть исходный main и проверенная резервная копия; при переключении сохранить оставшиеся незакоммиченные материалы.

Первая проба с высотой 133 px заменена системой 126 px после уточнения иерархии. Общий прогон первой пробы был остановлен на 33 успешных тестах и не считается завершённым. Навык session-memory использован для сохранения исходной точки, решений и проверок.
