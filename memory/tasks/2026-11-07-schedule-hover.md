## Итоговый вариант

- Общая плашка активного лимита получает его собственный цвет: фон16%, внутренний контур1px/75%. Используется существующая клубная палитра, включая её изменения администратором. Новых pointer-обработчиков или React-состояния нет.
- Подсказка времени у слота сохранена. При смене лимита/дня и уходе курсора подсветка следует существующему механизму наведения.
- Контур активной даты перенесён внутрь плашки: inset2px вместо выступавшего outline с offset2px. Сегодняшняя дата сохраняет свой тёплый фон.
- Между лимитами непрерывная нейтральная линия1px/16% foreground; между видами — серая2px/22%. Линия проходит через подпись и слотную сетку без разрыва. Плавно затухают только наружные концы.
- По последнему прямому указанию Алексея цветной линии между днями нет. Самое сильное разделение задают рамки и увеличенный внешний отступ10px вместо6px.
- Фактические зазоры между слотами:2/6/10/18px. Пятистрочный день с промежутком130px вместо прежних170px; метки20×20 и ширина1181px сохранены.

Цветной разделитель между видами Алексей отклонил как слишком заметный. По его следующему поручению попробовали цветную линию между днями, затем убрали её. Эти предложения не являются действующим оформлением. Ёмкости50=3 и100=2 относятся только к локальному Demo.
