## Серверные проверки

- Временный API-клиент на5мин использован только для smoke и отозван. Секрет очищен из игнорируемого файла, в отчёте и git его нет. В реестре осталась отозванная служебная запись, чтобы не стирать след проверки.

- Root RPC create/revoke и отказ authenticated без identity проверены в rollback-транзакции; временные изменения теста не сохранены.
- Закрытые таблицы API имеют RLS и не дают authenticated SELECT. Cron prune активен. Security WARN до/после одинаковы; INFO RLS-no-policy +4 ожидаемы для приватных таблиц.
- Три миграции установлены штатным Supabase apply_migration; только их новые версии истории нормализованы к каноническим номерам файлов (без изменения предыдущей истории). Функция v1 ACTIVE, verify_jwt=false только у external-api; собственный X-API-Key обязателен.
