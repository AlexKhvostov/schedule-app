## Реализация

- [Новая миграция](../../supabase/migrations/20261103165923_external_api_snapshot_pages.sql): приватные snapshots/snapshot_pages, единый SQL-срез записей и метаданных, страницы по1000, случайные cursor, связь с клиентом, повторная авторизация, TTL15мин и cron-очистка5мин. Исходная RPC заменена без параллельной реализации/неоднозначной перегрузки. Старую миграцию не переписывали.
- [Контракт API](../../supabase/functions/external-api/README.md) и [OpenAPI](../../supabase/functions/external-api/openapi.json): первый запрос date/days/фильтры, далее только cursor + тот же ключ; все страницы одного snapshot_id. `slots_count` — текущая страница, `total_slots` — весь снимок. Поле complete раннего неопубликованного прототипа удалено; окончание по has_more=false.
- Все даты повторяются на каждой странице; клиент накапливает линии/метки по ID, пустые массивы относятся к странице. Срок не продлевается чтением, повтор cursor детерминирован.410 для недоступного/истёкшего/чужого курсора требует сброса частичной выгрузки и нового запроса.
- Старый предел10000 меток снят. Ресурсные границы реализации:250000 меток/128 MiB на снимок,4 MiB на сырую страницу,5 MiB на HTTP;30 живых снимков/256 MiB на ключ. Ошибки422/429 явные, незавершённый снимок откатывается. Снимок — временный артефакт, не постоянная месячная таблица.
- [Инструкция внешнему разработчику](../../supabase/functions/external-api/BOT-CONNECTION.md) содержит будущий адрес текущего проекта, заголовок, порядок страниц/повторов, ошибки и рекомендации хранения; секретов в ней нет. README поясняет владельцу генерацию key/sha256, регистрацию и передачу отдельно от инструкции. Реальный ключ внешнему разработчику не выпускался/не передавался.
