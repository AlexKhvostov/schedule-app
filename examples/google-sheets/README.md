# Google Sheets: клиент API v2

Пример связанного Google Apps Script: [Code.gs](Code.gs). Данные только читаются из RedParty;
изменения в таблице не записываются обратно в расписание.

1. Создайте приватную Google Таблицу и откройте «Расширения → Apps Script».
2. Вставьте Code.gs, задайте `RP_.date` и фактическое число дней месяца.
3. Выполните `setupRedParty`. Скрипт создаёт ключ только в Script Properties и печатает только SHA-256.
4. Администратор регистрирует этот hash как отдельное подключение с правом `schedule:read`.
   Не помещайте исходный ключ в код, ячейки, сообщения или журналы.
5. Выполните `syncNowStatus`, проверьте листы Расписание, Люди и Синхронизация.
6. Выполните `setupCalendar`: главный лист станет цветной сеткой, исходный список «Слоты» будет скрыт.
   Затем выполните `installAutoRefresh`. Минутный триггер вызывает API после истечения180секунд;
   Google не гарантирует точный интервал. `stopAutoRefresh` отключает запросы.

Код использует `@OnlyCurrentDoc`, Script Properties и LockService. Полный месяц загружается
один раз, затем запрашиваются последние состояния по курсору. Все страницы собираются до записи.
Курсор сохраняется после записей и flush. Google Sheets не предоставляет транзакцию нескольких
листов: при частичном сбое старый курсор сохраняется, повтор пакета восстанавливает данные.
При изменениях переписываются данные листов пакетно; при `unchanged` они не читаются и не переписываются.
Ответ410 приводит к одной полной пересинхронизации;429 и временные ошибки — к отложенному повтору.
401/403 отключают автоматические запросы. Технические ID скрыты, но скрытие не является защитой доступа.
Не предоставляйте доступ к таблице/скрипту людям, которым нельзя видеть расписание или ключ.

Часовой пояс слотов — Europe/Madrid; время проверок — Europe/Minsk.
При смене месяца меняйте конфигурацию и начинайте новый локальный набор без старого курсора.
Этот пример настроен на ноябрь2026, автоматического переключения месяца нет.

Проверки: `node --test examples/google-sheets/client.test.mjs` из корня репозитория.
`verifyV1` — ограниченная проверка совместимости старого API с тем же ключом.
Детальный контракт: [V2-SYNC.md](../../supabase/functions/external-api/V2-SYNC.md).

Сетка: дни и линии по вертикали,48получасов по горизонтали, метки/цвета игроков. Показываются линии с занятостью в месяце. Серые запрещённые часы в текущем API не передаются; пустоты показываются белыми, без выдуманных блокировок.
