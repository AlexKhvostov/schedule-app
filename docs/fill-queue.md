# Очередь заполнения расписания

Реализовано локально 18 ноября 2026. Совместимые изменения базы и новый обработчик Discord находятся в репозитории. Статус проверок и адрес локального просмотра описаны в [инструкции запуска](operations.md#доставка-очереди-планирования).

## Действия игрока

1. Открыть нужный месяц расписания и окно «Игроки месяца». Выбрать Nitro 50–100, Expresso 50–100 или общую очередь 250–500.
2. Яркая галка показывает, чей ход. Расставить цветные метки в сетке. По кнопке подсказки в шапке окна доступны эти шаги и пояснение порядка.
3. Когда текущий игрок закончил, нажать яркую галку. В диалоге сверить игрока, месяц, закладку, следующего и параметры Discord. Нажать «Согласен» или «Отмена».

Галка — подтверждение завершения или досрочного пропуска. Цветная метка — запись в ячейке сетки. Галка сохраняется отдельно по месяцу и закладке. Первый игрок может начинать сразу. Другой игрок с действующим доступом к расписанию может подтвердить за текущего. Обычный игрок не может снять галку, а после завершения может дополнять свои метки. В списке яркой остаётся только галка текущего.

Ожидающий может заранее нажать свою приглушённую галку и подтвердить, что пропускает ход в этом месяце. Диалог сообщает о пропуске без уведомлений. Текущий ход остаётся на месте. При следующей передаче бот выбирает первого без галки и пропускает тех, кто заранее отказался от хода. При включённой блокировке пропуск не даёт права редактировать до конца очереди. После её завершения действуют обычные права.

Текущий игрок — первый без галки в актуальном порядке, в том числе после пересчёта рейтинга. Игроки вне рейтинга остаются справочными. Когда у всех участников есть галки, очередь завершена. Повтор подтверждения не повторяет запись и рассылку. Если открытый диалог устарел, сервер перепроверяет текущего и следующего перед записью.

## Блокировка и журнал

Клубный переключатель «Блокировать правку до своего хода» расположен в настройках расписания, в блоке управления. По умолчанию выключен. При включении правят текущий и завершившие. Сервер проверяет фактического автора, а при постановке новой метки — также её владельца. Метка ожидающего не ставится даже чужой кистью. Для пар вне этих трёх очередей действуют обычные права. Все ограничения прошедших, закрытых и недоступных слотов продолжают применяться.

В журнале Root постановка и снятие цветной метки сохраняют прежний аудит. Галка добавляет событие «Подтвердил завершение» или «Пропустил очередь». В нём видны автор, игрок, дата, месяц расписания, закладка и, если была рассылка, результат по назначениям. Галка и аудит фиксируются вместе.

## Discord

Root → Discord → Автоуведомления содержит один переключатель для канала и лички и поля ID каналов для трёх очередей. Один ID можно указать несколько раз. При пустом ID для конкретной очереди доступна личка. При выключенной рассылке передача хода работает через приложение.

Бот уведомляет после подтверждения завершения. В канале короткими строками показывает, кто закончил, закладку и месяц, затем упоминает только следующего и даёт ссылку «Открыть расписание». В личке первая строка — «Ваш ход!», следом месяц, закладка и ссылка. Результаты канала и лички независимы. Сбой Discord не откатывает галку. Повторяются только временные сбои в пределах предусмотренных попыток. Подробности включения обработчика — в [операциях](operations.md#доставка-очереди-планирования).
