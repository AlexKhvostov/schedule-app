# UI: Tailwind + shadcn/ui

**Решение:** каркас на **Tailwind CSS + shadcn/ui**. Плотность задаём сами. Ant Design не используем.

Канон — издание **next**: тёмное поле, ширина **1440px** по центру, живое расписание. Старое сравнение classic из меню убрано.

Подробные правила поля, календаря и ёмкости — в [schedule-ux.md](schedule-ux.md).

- Меню, шапка, селекты, таблицы, формы — компоненты shadcn в `apps/web/src/components/ui` (их можно менять).
- Сетка слотов месяца — **наш** компонент. Цвета зон (шапка часов, день, уровень, пустой слот, прошлое) задаются в UI-ките → **Слоты** и сразу видны на Расписании. Заводская схема: пустой слот `--background`, прошлое `--slot-past`, день и уровень `--card`.

## UI-кит и Блоки

Это лаборатория команды, не экраны игрока. Открываются из меню **Админка** у root (не из кабинета игрока), рядом с пунктом **Сервер**.

| Страница | Что там |
|---|---|
| **UI-кит** | Кирпичи: токены, кнопки, поля, аватар, одна клетка, песочница цветов сетки |
| **Блоки** | Собранные секции: ожидание, платежи, VIP, фильтр людей, один день сетки |

Фрагмент сетки в Блоках — тот же день, что в «Слотах», чтобы цвета не разъезжались.

## Зачем так

Это обычная связка для кабинетов на **React / Next.js**: современный вид, полный контроль отступов, те же компоненты поедут в боевой сайт.

## Где смотреть образцы

- [ui.shadcn.com](https://ui.shadcn.com/) — компоненты
- [Пример dashboard](https://ui.shadcn.com/examples/dashboard) — админка (там воздух; мы ужежимаем)
- [Темы](https://ui.shadcn.com/themes)

Плотность сетки и таблиц настраиваем классами Tailwind (`h-6`, `text-[10px]`, `p-1`), а не «как в демо на сайте».

В «Контроле дистанций» итог участника крупнее и жирнее слагаемых внутри: числа по лимитам 12 px / 700 против 10 px / 500 при высотах строк 26/24 px. Редактируемые записи и кнопка «Править» получают изумрудный оттенок из `--title` текущей темы, в том числе при наведении; верхняя строка сохраняет свой фон, раскрытая группа обведена общей рамкой.

Основной акцент таблицы — числовая дистанция. `colgroup` и fixed layout оставляют идентичности 192 px слева, ID44 px, виду60 px, правке80 px справа; все числовые колонки распределяют оставшуюся ширину с минимумом76 px на колонку. ID/вид имеют меньший вес и приглушённый цвет; полный ID доступен через title и редактор, длинный отображается с многоточием. Лимиты подписаны в €, табличные цифры и группировка разрядов сохранены, значения выровнены справа, тонкие вертикали отделяют лимиты. «Всего» получает усиленный разделитель, цвет `--title` и числа13 px / 750 (итог участника) против11 px / 600 (part). Дата изменения убрана только из таблицы, сохранена в редакторе и CSV. На ширине≤560 px колонки ID/вида свёрнуты через `visibility: collapse` у col, идентичность144 px и правка44 px закреплены; кнопка правки — карандаш с прежним доступным именем. Первая числовая колонка полностью видна даже до горизонтальной прокрутки.

Фильтры и информационная сводка — две самостоятельные именованные панели. Четыре группы фильтров внутри одной рамки разделены линиями; поля попарные, высота контролов 26 px на desktop и 28 px на телефоне. Сводка — короткая строка пар название/значение с разделителями и мягким изумрудным фоном; при недостатке ширины пары располагаются в двух колонках. Связь панели и заголовка задаётся `aria-labelledby`, подсказка статуса дистанции — `aria-describedby`.
