# UI: Tailwind + shadcn/ui

**Решение:** каркас на **Tailwind CSS + shadcn/ui** (тёмная тема, плотность задаём сами). Ant Design больше не используем.

- Меню, шапка, селекты, таблицы, формы — компоненты shadcn (лежат у нас в `src/components/ui`, их можно менять).
- Сетка слотов месяца — **наш** компонент на Tailwind: одинаковые клетки, кит её не рисует.

## Зачем так

Это обычная связка для кабинетов на **React / Next.js**: современный вид, полный контроль отступов (можно очень компактно), те же компоненты поедут в боевой сайт.

## Где смотреть образцы

- [ui.shadcn.com](https://ui.shadcn.com/) — компоненты
- [Пример dashboard](https://ui.shadcn.com/examples/dashboard) — админка (там воздух; мы в песочнице ужежимаем)
- [Темы](https://ui.shadcn.com/themes)

Плотность сетки и таблиц настраиваем классами Tailwind (`h-6`, `text-[10px]`, `p-1`), а не «как в демо на сайте».
