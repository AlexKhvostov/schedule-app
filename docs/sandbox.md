# Песочница: живой продукт и переход в бой

Каталог: `sandbox/ui`. Запуск:

```bash
cd sandbox/ui
npm install
npm run dev
```

Обычно http://localhost:5173/. С ключами Supabase (`.env.local`) это уже **рабочий клубный интерфейс** на живой Postgres, не макет. Те же экраны перенесены в `apps/web` (Vercel). Песочница остаётся локальной лабораторией.

Правила экрана и кликов — [schedule-ux.md](schedule-ux.md). Свежий статус поля — [schedule-now.md](schedule-now.md). К чему не возвращаемся — [decisions.md](decisions.md).

## Что умеет игрок и админ

- Вход **только Discord**. Заявка, экран ожидания, кабинет.
- **Расписание next**: дни вниз, часы вправо, 30 мин, CET. Галка правки, клик и протяжка, кисть admin/root за другого (только игроки, без staff).
- Слоты пишутся в `occupancy`, другим приходят через realtime.
- Мой календарь, аналитика, игроки месяца, настройки вида поля (прошлое, столы, подсказка, своё время).
- Кабинет: анкета, канал уведомлений (Discord / Telegram / почта), Winamax Nitro/Regular, платежи. Админ видит **тот же кабинет** плюс служебные поля и может сменить канал бота.
- Админка: заявки, люди (фильтр по умолчанию «участники и админы»), доступы к сетке, ёмкость, VIP, галки клуба (чужие метки, столы). Видят администратор и root. Staff в расписании не показывается.
- Root: три карточки на бота (настройки, автоуведомления, отправка). Токен только запись. Писать от имени бота — только Root.

## Меню

Шапка живого продукта (`apps/web`):

| Где | Что |
|---|---|
| Слева | Расписание, Приоритеты |
| Справа | **Админка** (люди, настройки сетки; у root ещё Root, UI-кит, Блоки, Сервер) |
| Аватар | Кабинет, тема, язык, выход |

Кнопка «Админка» в шапке — меню admin/root. Это **не** клубный статус staff.

| Пункт | Кто видит |
|---|---|
| Кабинет | все, кто вошёл |
| Админка: люди и сетка | administrator и root |
| Root, UI-кит, Блоки, Сервер | только root |

Игрок лабораторию не видит. Старую сетку (Архив) из меню убрали.

## Лаборатория, не продукт

UI-кит и Блоки нужны команде, не клубу. Они стоят в блоке **Root**:

| Экран | Зачем |
|---|---|
| **UI-кит** | Кирпичи: токены, поля, кнопки, клетка слота, песочница цветов сетки |
| **Блоки** | Собранные куски кабинета и один день сетки |
| **Сервер** | Снимок Discord, бот |

Цвета сетки крутим в UI-ките → «Слоты». Правка сразу видна на Расписании. Заводская схема лежит в коде (`DEFAULT_SLOT_THEME`). Панель «скопируйте код и пришлите» из шестерёнки игрока убрана.

## Сверка 22 сентября 2026

За последнее время устаканилось:

- Живая сетка, галка правки, протяжка, кисть за другого, журнал `occupancy_events` (пишется сам, экрана нет).
- Свою метку рисуем сразу. После своей записи месяц целиком не качаем — иначе метка мигает. Чужие правки — realtime.
- Галки клуба: удалять чужие, заменять чужие, работа со столами (сейчас выкл). Снятие и замена — одно окно согласия (чип, аватар, ники, слот, схема).
- Бот Discord: снимок сервера; снятие чужой метки в канал и в личку обоим (текст всегда «удалена»); ручная отправка только Root. Токен только запись.
- Канал уведомлений в кабинете и в карточке человека. Telegram и почта — выбор на будущее.
- Доступ к лимитам сетки отдельно от кабинетных бай-инов (`member_schedule_access`).
- Метка необязательна. Прошлое — серый токен темы; линия «сейчас» без пульса. Пустой второй уровень без подписи `50·2` — прозрачная полоса, день не схлопывается.
- Кабинет = карточка человека в админке. Платежи, VIP, поручитель, публичное только имя.
- Снимок Discord-сервера. Статусы: закрыт / участник / админ / staff; root — сервис, в списке последним. SQL `is_staff()` = admin или root.
- Игроки месяца — часы на поле (`4.0` / `—`), шапка `50 €, ч`. Остаток часов — в «Моих часах». Аналитика — по каждому лимиту.
- Живая ёмкость — все единицы. Сид и сброс матрицы — день 1 / ночь 2.
- Каркас таблицы `distances` (пустая). Импорт рук — позже.
- Pinch-zoom сетки и автоматизация очереди — не сейчас.
- UI-кит и Блоки разведены: кит — атомы, блоки — собранные секции. Цвета слотов — токены темы, не старые hex classic.

Старые HTML-наброски: `sandbox/legacy-html` — архив.

## Переход к `apps/web`

Песочница остаётся местом, где **вид уже собран**. Next.js — рамка сайта (маршруты, SSR, хостинг), не второй макет.

Переносим **те же компоненты** из `sandbox/ui/src/v2` и `sandbox/ui/src/components/ui`, плюс словари `locales`, данные `src/data`, расписание `src/schedule`. Не рисуем экраны заново.

**В бой:** вход Discord, ожидание, кабинет, расписание next, приоритеты, админка, сервер. **UI-кит и Блоки** тоже едут, но их видит только root — кирпичи ищутся в одном месте, не в двух репозиториях экранов.

Демо-кнопки входа и издание classic в продукт не едут.

Схема базы: [database.md](database.md). Что в MVP: [mvp.md](mvp.md).
