# Песочница: что уже есть и чего нет

Чтобы не путать **живой макет** с **боевым MVP**.

Каталог: `sandbox/ui`. Запуск:

```bash
cd sandbox/ui
npm install
npm run dev
```

Откроется локальный Vite (часто порт 5173 или 5174).

## Уже можно смотреть

По умолчанию открывается издание **next** (тёмное поле 1440). Кнопка **sandbox** в шапке возвращает классику. Правила экрана — [schedule-ux.md](schedule-ux.md).

- Шапка: CET (главное) и МСК, язык, вход в кабинет через ник.
- **Расписание next** — дни вниз, часы вправо, всегда уровни. Сегодня при загрузке — третья строка. Затемнение на красной линии «сейчас».
- **Мой календарь** — иконка справа, модалка: одна строка на дату, смены цветом лимита, скачать JPEG.
- **Настройки** — иконка-шестерёнка: прошлое, столы, подсказка слота.
- **Админка ёмкости** — матрицы месяца 31×24 и недели 7×24, глубина 1–6, при конфликте дня и числа побеждает меньшая ёмкость.
- **Классика** — плотная таблица месяца и **Сетка** «как GitHub».
- Поиск метки, аналитика и игроки (плавающие окна).
- Каркас **кабинета**.

Свежий статус «что доделали» — [schedule-now.md](schedule-now.md).

Клик по слоту ставит или снимает метку **YO** (вы), если слот не прошёл и уровень открыт.
