# Песочница: что уже есть и чего нет

Чтобы не путать **живой макет** с **боевым MVP**.

Каталог: `sandbox/ui`. Запуск:

```bash
cd sandbox/ui
npm install
npm run dev
```

Откроется локальный Vite (часто порт 5173 или 5174).

## Уже можно смотреть

- Шапка: CET (главное) и МСК, язык, вход в кабинет через ник, меню-бургер.
- **Расписание** — плотная таблица месяца. Правила клетки — [schedule-ux.md](schedule-ux.md).
- **Сетка** — тот же месяц «как GitHub».
- Компактные фильтры, поиск метки, затемнение прошлого, аналитика и игроки (плавающие окна).
- Каркас **кабинета** и **админки** (список меток, не настоящие заявки).

Клик по слоту ставит или снимает метку **YO** (вы), если есть свободное место.
