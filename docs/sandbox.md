# Песочница: живой продукт и переход в бой

Каталог: `sandbox/ui`. Запуск:

```bash
cd sandbox/ui
npm install
npm run dev
```

Обычно http://localhost:5173/. С ключами Supabase (`.env.local`) это уже **рабочий клубный интерфейс** на живой Postgres, не макет. Боевой каркас Next.js — `apps/web`; плотное поле туда ещё не перенесено.

Правила экрана и кликов — [schedule-ux.md](schedule-ux.md). Свежий статус поля — [schedule-now.md](schedule-now.md). К чему не возвращаемся — [decisions.md](decisions.md).

## Что умеет игрок и админ

- Вход **только Discord**. Заявка, экран ожидания, кабинет.
- **Расписание next**: дни вниз, часы вправо, 30 мин, CET. Галка правки, клик и протяжка, кисть admin/root за другого.
- Слоты пишутся в `occupancy`, другим приходят через realtime.
- Мой календарь, аналитика, игроки месяца, настройки вида поля (прошлое, столы, подсказка, своё время).
- Кабинет: анкета, Winamax Nitro/Regular, платежи. Админ видит **тот же кабинет** плюс служебные поля.
- Админка: заявки, участники, доступы к сетке, ёмкость, VIP. Видят администратор и root.

## Меню аккаунта

| Пункт | Кто видит |
|---|---|
| Кабинет | все, кто вошёл |
| Админка | administrator и root |
| блок **Root**: UI-кит, Блоки, Сервер | только root |

Игрок блока Root не видит. Старую сетку (Архив) из меню убрали.

## Лаборатория, не продукт

UI-кит и Блоки нужны команде, не клубу. Они стоят в блоке **Root**:

| Экран | Зачем |
|---|---|
| **UI-кит** | Кирпичи: токены, поля, кнопки, клетка слота, песочница цветов сетки |
| **Блоки** | Собранные куски кабинета и один день сетки |
| **Сервер** | Снимок Discord, бот |

Цвета сетки крутим в UI-ките → «Слоты». Правка сразу видна на Расписании. Заводская схема лежит в коде (`DEFAULT_SLOT_THEME`). Панель «скопируйте код и пришлите» из шестерёнки игрока убрана.

## Сверка 20 сентября 2026

За последнее время в песочнице устаканилось:

- Живая сетка, галка правки, протяжка, кисть за другого, журнал `occupancy_events` (пишется сам, экрана нет).

- Кабинет = карточка человека в админке. Платежи, VIP, поручитель, публичное только имя.
- Снимок Discord-сервера, роли root / administrator / member.
- Каркас таблицы `distances` (пустая). Импорт рук — позже.
- UI-кит и Блоки разведены: кит — атомы, блоки — собранные секции. Цвета слотов — токены темы, не старые hex classic.

Старые HTML-наброски: `sandbox/legacy-html` — архив.

## Переход к `apps/web`

Песочница остаётся местом, где **вид уже собран**. Next.js — рамка сайта (маршруты, SSR, хостинг), не второй макет.

Переносим **те же компоненты** из `sandbox/ui/src/v2` и `sandbox/ui/src/components/ui`, плюс словари `locales`, данные `src/data`, расписание `src/schedule`. Не рисуем экраны заново.

**В бой с игроком:** вход Discord, ожидание, кабинет, расписание next, приоритеты, админка, сервер (root).

**Не переносим как продукт:** UI-кит, Блоки, панель подбора hex слотов, демо-кнопки входа. Старое издание classic из меню убрано.

Пока `apps/web` — тонкий каркас (Discord, wait, список слотов, апрув). Плотное поле живёт здесь, в Vite.

Схема базы: [database.md](database.md). Что в MVP: [mvp.md](mvp.md).
