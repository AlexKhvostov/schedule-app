# Структура репозитория

```
schedule-app/
  README.md
  docs/                      продукт, сущности, стек
  apps/web/                  боевой Next.js (пока заглушка)
  sandbox/ui/                песочница: Vite + React + Tailwind + shadcn
  sandbox/legacy-html/       архив HTML-набросков, не используем
  references/                старые таблицы (не в git)
```

Порядок работы: вид в `sandbox/ui` → перенос компонента в `apps/web`.
