# MVP

## Входит

- Вход Discord, заявка, апрув админом.
- Кэш профиля Discord (аватар, ники) при входе.
- Роли в нашей базе; подтягивание при входе.
- Две роли на старте: админ и участник. Остальное — расширение справочника.
- Профиль, метка, игроки/ники (хотя бы один рум).
- Справочники: рум, лимит, формат, вариант, вид расписания.
- Сетка 30 мин, канон — испанское время (CET); второй пояс в шапке и второй строкой над часами (в песочнице МСК).
- Занятость, конфликт «один человек — одно время», ёмкость правилами (в песочнице матрицы в админке, старт **день 1 / ночь 2**, до 6 линий). На экране несколько мест = несколько линий уровня.
- Взгляд на месяц: канон **next**; классика (таблица + сетка как GitHub) остаётся для сравнения. Правила UX — [schedule-ux.md](schedule-ux.md).
- Живое обновление слота у других.
- Интерфейс на русском и английском (словари с первого экрана).

## Не входит

- Расчёт приоритета и импорт всех архивных дистанций (каркас таблиц можно заложить).
- Платёжные реквизиты можно показать каркасом, не обязательно заполнять всем.
- Бот Discord, крон синка, скрейпер столов, запрет доп. слота по числу столов.
- Совмещённая лента нескольких лимитов в классике. В next несколько лимитов уже стоят стопкой в одном дне.
- Дележка денег.

## Регистрация

Два пути: сам через Discord (заявка) и админ заводит участника, Discord привяжет позже.

Без апрува человек видит пустой экран ожидания, не сетку.
