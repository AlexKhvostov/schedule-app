# Технологии (фиксируем, чтобы не путаться)

Это договорённость. Новые экраны и компоненты делаем **только** в этой связке.

Этот файл нужно обновлять в той же работе, где добавляется, удаляется или существенно меняется технология, библиотека, внешний сервис либо способ их использования. Для долгосрочного выбора с заметными последствиями дополнительно фиксируется причина в [decisions.md](decisions.md); обычное обновление версии без изменения подхода отдельного архитектурного решения не требует.

## Что используем

| Задача | Технология | Где живёт |
|---|---|---|
| Боевой сайт | **React** внутри **Next.js** | `apps/web` |
| Таблицы и вход | **Supabase** (EU) | `supabase/migrations` |
| Локальная разработка UI | **Next.js dev** | `apps/web` |
| Историческая UI-лаборатория | **React** + **Vite** | `sandbox/ui`, новые функции туда не добавляем |
| Стили и контролы кабинета | **Tailwind CSS** + **shadcn/ui** | `apps/web` |
| Сетка слотов на месяц | **Свои React-компоненты** на Tailwind | ни один кит не умеет 48×31 клеток |
| База, Discord-вход, живые слоты | **Supabase** (Postgres, Auth, Realtime), регион EU; сетка использует private Broadcast из DB-триггеров и компактную JSON-RPC, без серверного кэша | облако |
| Выкладка сайта | **Vercel** | облако |
| Скрейпер (позже) | **Render** (уже есть аккаунт) | отдельный сервис, не сайт |
| Discord-бот (снимок, снятие метки, отправка Root) | **Supabase Edge Functions** | `discord-guild`, `notify-mark-removed`, `bot-send` |
| Внешний API для машинных клиентов | **Supabase Edge Function**, Deno/TypeScript, встроенный fetch → закрытая RPC, Postgres-снимки/страницы и существующий pg_cron для очистки; без сторонних runtime-импортов | `supabase/functions/external-api`; контракт OpenAPI3.1, тестовый Deno2.9.6 |
| Интерфейс RU / EN | **i18next** | `apps/web/src/locales` |

Язык интерфейса в коде: **TypeScript**. Тексты UI — только в `locales/ru.json` и `locales/en.json`.

## Как это связано

**Next.js = React + рамка сайта** (страницы, сервер, деплой на Vercel).  
`apps/web` — единственная каноническая реализация. Vite-песочница больше не является промежуточным обязательным этапом и не должна получать отдельную копию новой бизнес-логики.

**Tailwind** — утилиты для вида и плотности. **shadcn** — готовые кнопки, меню, таблицы, поля; код наш, не «чёрный ящик».  
Сетку расписания всё равно рисуем сами.

## Чего не используем

5 ноября 2026: Алексей подтвердил **React/TypeScript для Dashboard**, с сохранением действующих PHP-расчётов и MySQL внешней аналитики. Первая оболочка реализована локально: `React.lazy`, CSS Modules, отдельное лениво загружаемое пространство i18next `analytics`; новых зависимостей нет. Импортированные Vue/Vite/Pinia/ApexCharts в `modules/analytics/upstream` используются только как референс и не входят в приложение. Для первого графика реализован собственный небольшой SVG-адаптер с диапазоном времени, легендой и текстовыми значениями; сторонний графический движок не установлен; [план границ и переноса](analytics-dashboard-plan.md). Серверное подключение пока не реализовано.

| Не берём | Почему |
|---|---|
| Vue / Nuxt | Другая экосистема, мы уже на React |
| Vanilla HTML как основной UI | Компоненты не те, что поедут в Next.js |
| Ant Design | Сменили на Tailwind + shadcn |
| Tabler / Bootstrap / AdminLTE как основа | HTML-админки, не React |
| Свой VPS и ручной Linux | Пока хватает Vercel + Supabase + Render |
| Discord API на каждый клик | Права только из нашей базы |

Старые HTML-наброски лежат в `sandbox/legacy-html` как архив, на них не опираемся.

Панель Root → API использует встроенный Web Crypto (`getRandomValues`, `subtle.digest`, `randomUUID`) для индивидуальных ключей и нативный HTML dialog для модальных окон/фокуса. Новых npm-зависимостей нет. Хеш передаётся через существующий Supabase RPC, raw key в базу не отправляется.

Согласованное подключение Dashboard: React в текущем приложении → HTTPS к PHP API → прежняя MySQL. Аутентификация/права проверяются в PHP; дополнительная серверная технология для доступа к аналитике не вводится. Пока зафиксирована архитектура, не выполнено подключение.

5 ноября2026, локально: существующие React lazy/Suspense применены также к экранам входа и заявки (V2Login/V2JoinGate); новые зависимости не добавлялись. Сверка расписания использует AbortSignal и ограниченное ожидание чтения, а интерфейс отделяет наличие снимка от подтверждённой актуальности. [Архитектура](code-architecture.md), [проверки](../memory/tasks/2026-11-05-sync-health-implementation.md).

Dashboard, продолжение5ноября: без новых зависимостей добавлены SVG-линия/столбцы по24часам и переиспользуемая HTML-карта месяца. Intl.DateTimeFormat отвечает за часыEurope/Madrid; native dialog — детали с Escape/возвратом фокуса. UI/тексты и synthetic sources остаются лениво загружаемыми, реальный PHPHTTP не подключён к браузеру.

Dashboard6ноября: для отзывчивых SVG используется браузерный ResizeObserver; новых npm-зависимостей нет. UI-переключатели — native radio, обе темы задаются локальными CSS-переменными. Рабочий процесс frontend-design применён к палитре/иерархии и визуальной критике, без установки стороннего исполняемого кода.


6 ноября2026: Dashboard использует встроенный браузерный fetch/AbortController для локального read-only HTTPS PHP-источника, без новых пакетов/прокси. Production-источник не включён до серверного допуска. Native HTML dialog сохранён, оформление вынесено в отдельный CSS Module с центрированием и прокруткой тела.
