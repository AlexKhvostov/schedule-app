# Сюда кладём старые таблицы

Папка для выгрузок из Google Sheets / Excel: расписание, дистанции, шапки колонок, скрины сеток.

Файлы внутри **не уходят на GitHub** (это прописано в `.gitignore`). Сюда можно класть рабочие копии как есть.

Как назвать файлы, чтобы было понятно:

- `schedule-...` — сетка расписания
- `distance-...` — дистанции по месяцам / лимитам / типам
- `priority-...` — как считали или вручную ставили приоритет
- `headers-...` — если это только шапки колонок
- `admin-...` — настройки лимитов, сколько человек на слот и т.п.

Можно несколько файлов и короткую текстовую заметку рядом (`notes.txt`), что на каком листе смотреть.
